Tasks Help

The window

The sidebar on the left lists the views (Favorites, All Tasks, 3-Day Forecast, Action Items), then your lists and groups of lists, then your tags. Favorites appears only while something is starred, and Action Items only while there are items from Notes. The pane on the right shows the tasks of whatever is selected there, as a list or as a Kanban board. The bar along the bottom says how many tasks are showing and, for a few seconds, what the last action did.

A new task goes into the selected list, so select a list first: a view or a group has no one list to put it in.

Searching

The search field narrows the selected view; it does not search the whole database. It looks in each task's title, its notes and the titles of its subtasks, ignoring case. It searches titles as they are shown, so with the note's context shown before action items' titles (below), searching for a Notes folder's name finds the items written in it.

bank lettertasks containing both words
"bank letter"tasks containing that phrase
bank -lettertasks containing “bank” but not “letter”

Press Escape in the field to clear the search. While a search is active tasks cannot be dragged into a manual order, because the hidden tasks would lose their places.

Action items from Notes

A line marked as an action item in a note is a task here too. Its editor says which note it came from, and its title, completion and due date stay in step with the line in the note.

The Action Items view, after the 3-Day Forecast, lists every task that came from a note, whichever list you have since moved it to. It is shown only while there is at least one, and appears by itself when Notes writes the first.

Settings > Appearance > Show the note’s context before Notes action items’ titles shows the name of the folder the note is in before the item's title, wherever the task is listed: the list, the Kanban board, the 3-Day Forecast, Action Items, the day planner and reminders. An item written in a note in the folder “Captain’s Log” then reads “Captain’s Log - lock down my diet RE keto”. This only changes what is shown: the title you edit, the line in the note and what goes to Google Calendar stay as they are. A title that already starts with the folder's name and a “-” or “:” is shown as it is, and an item from a note at the top level (not in a folder) has no context to show. The option is on until you turn it off.

Tags

The Tags field in a task's editor, below Status, gives the task any number of tags. As you type, the tags that already exist are offered: choose one with the arrow keys or a click. Press Return to make what you typed a tag; if no tag has that name, a new one is created. Names ignore case, so “work” is the same tag as “Work”. To take a tag off, delete its token.

Each tag has a 🏷️ button after your lists. It shows every task carrying the tag, from whichever list, just as a list shows its tasks. New Task there adds the task to the default list and gives it the tag. A tag lasts only while a task carries it: when the last one loses it, or is deleted, the tag and its button go.

New tasks and Quick Task

New Task (⌘N) adds a task to the selected list. With a group, a tag or a view such as All Tasks selected, it goes to the default list (and, for a tag, gets that tag), which you choose in Settings under New Tasks; with no default list, select a list first. New Task is not offered in Action Items: those come only from Notes.

Quick Task (⌃⌥⌘T) always adds its task to the default list, whatever is selected, and opens the task's editor in the lower-right corner of the screen. The shortcut works from any app while Tasks is running; turn that off in Settings if another app needs the keys. Cancel (or Escape) throws the new task away.

Compact Controls

View > Compact Controls shrinks the window to a small size it remembers, hides the sidebar and the toolbar, and floats the New Task and Delete Task buttons at the bottom-right of the tasks. It also clears any search, since the search field is hidden. View > Full Controls puts the window back as it was, with the sidebar showing.

Opening another database

Notes and Tasks keep their data in one shared database file, so a task changed in one app appears in the other within a second. File > Open Database File… switches to another shared database file. The file is checked before anything changes: a file that is damaged, empty, or is not a shared Notes and Tasks database (an old tasks.db included) is refused and left as it is, and so is one inside iCloud Drive, Dropbox or another synced folder. You are then asked whether to Make Default: both Notes and Tasks open the default database at every launch. Cancel keeps it open in Tasks for this session only.

Backups

Backups are on by default: every hour a checked copy of the database is written, keeping the newest 48. Settings sets how often, how many are kept and the folder they go to; by default it is a backups folder beside the database file. Notes and Tasks share these settings, and whichever app is running makes the backup. Each backup is named for the moment it was made, in UTC (shared_data-20261012-140500Z.db). Back Up Now makes one at once; if the last backup failed, Settings says why.

If another app holds the database for too long and a change cannot be saved, Tasks says so in the status bar. A task editor keeps your changes and saves them again with the next change or when it closes; it will not close while they cannot be saved.

Google Calendar

The day planner can be kept in step with your Google Calendar. Turn it on in Settings: press Sign In to Google…, approve the request in your browser, and tick Sync the day planner with Google Calendar.

Your meetings then appear in the planner, in their calendar's colour, so you can schedule around them; all-day events are listed under the date. They cannot be moved from here. A task you drag onto the planner becomes an event in the calendar chosen under Add scheduled tasks to. Moving or stretching it moves the event, and Remove from Schedule or deleting the task deletes it. It works the other way too: move the event in Google Calendar and the session moves here; delete it there and the task leaves the planner. If you change a session here and in Google before they sync, the change made here wins.

The planner sends each change you make a couple of seconds after you make it. It also syncs on a timer, every five minutes unless you change Sync every … minutes, and when you press Sync Now. The timer decides how soon changes made in Google Calendar reach the planner; 0 turns it off. It shows events from a week ago to two months ahead. Declined invitations are left out. Your sign-in is kept in the macOS keychain; Sign Out removes it.

Where the data is kept

The shared database (shared_data.db) and its backups are in ~/Library/Application Support/camb.io/, unless a different default database was chosen with Open Database File… (its backups then go beside it). Tasks' own settings (tasks.ini) are in ~/Library/Application Support/Tasks/.
