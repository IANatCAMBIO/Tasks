Tasks AppKit Help

The window

The sidebar on the left lists the views (Favorites, All Tasks, Due Today), then your lists and groups of lists. The pane on the right shows the tasks of whatever is selected there, as a list or as a Kanban board. The bar along the bottom says how many tasks are showing and, for a few seconds, what the last action did.

A new task goes into the selected list, so select a list first: a view or a group has no one list to put it in.

Searching

The search field narrows the selected view; it does not search the whole database. It looks in each task's title, its notes and the titles of its subtasks, ignoring case.

bank lettertasks containing both words
"bank letter"tasks containing that phrase
bank -lettertasks containing “bank” but not “letter”

Press Escape in the field to clear the search. While a search is active tasks cannot be dragged into a manual order, because the hidden tasks would lose their places.

Compact Controls

View > Compact Controls shrinks the window to a small size it remembers, hides the sidebar and the toolbar, and floats the New Task and Delete Task buttons at the bottom-right of the tasks. It also clears any search, since the search field is hidden. View > Full Controls puts the window back as it was, with the sidebar showing.

Opening another database

File > Open Database File… switches to another database file. The file is checked before anything changes; a file that is damaged or is not a database is refused. A database named tasks.db can then be made the default, opened at every launch; one with any other name stays open for the session only.

Keyboard shortcuts

⌘NNew Task
⇧⌘NNew List…
⌘IInfo… — open the selected task
⌘⌫Delete the selected tasks
⌘FFind — search the selected view
⌘OOpen Database File…
⌃⌘SHide or show the sidebar
⇧⌘KKanban View or List View
⌃⌘FEnter or leave full screen
⌘,Settings…
⌘WClose the window; closing the main window quits

Where the data is kept

The database (tasks.db), the settings (tasks.ini) and the backups are in ~/Library/Application Support/TasksAppKit/, unless a different default database was chosen with Open Database File….
